## Component 1: ArgoCD (`components/tool/argocd/`)

### C1 [CRITICAL] — Confirmed safety gate is dead code in 3 write tools

**Files:** `application_create.go`, `application_delete.go`, `application_sync.go`

The `Confirmed bool` param is declared with `jsonschema:"(optional) Must be true to actually execute..."` but never checked. Write operations execute unconditionally when `DryRun=false`.

**Fix `application_create.go:90`** — After the dry-run return block (line 90), add:

```go
if !params.Confirmed {
    return "", errors.Errorf("create aborted: Confirmed must be true. Use DryRun first to preview, then set Confirmed=true to proceed.")
}
```

**Fix `application_delete.go:65`** — After the dry-run return block (line 65), add:

```go
if !params.Confirmed {
    return "", errors.Errorf("delete aborted: Confirmed must be true. Use DryRun first to preview, then set Confirmed=true to proceed.")
}
```

**Fix `application_sync.go:55`** — The sync tool passes `DryRun` to the API via `SyncOptions`. Add after the `c.Application().Sync` call block ending at line 55 — but actually sync.go has no dry-run branch at all. Add before the Sync call:

```go
if !params.Confirmed {
    return "", errors.Errorf("sync aborted: Confirmed must be true. Use DryRun first to preview, then set Confirmed=true to proceed.")
}
```

## Component 4: libs/toolkit (`libs/toolkit/`)

### M7 [MEDIUM] — CELPolicy recompiles expressions on every Evaluate call

**File:** `safety/policy.go:38,53-55,82`

Cache compiled programs per rule. Add a `program cel.Program` field to `CELRule`:

```go
type CELRule struct {
    Name       string
    Expression string
    ToolNames  []string
    program    cel.Program  // cached
}
```

In `NewCELPolicy`, store the program after validation compile:

```go
for i, rule := range rules {
    ast, iss := env.Compile(rule.Expression)
    if iss.Err() != nil {
        return nil, errors.Wrapf(iss.Err(), "failed to compile CEL rule %q", rule.Name)
    }
    prog, err := env.Program(ast)
    if err != nil {
        return nil, errors.Wrapf(err, "failed to create program for CEL rule %q", rule.Name)
    }
    rules[i].program = prog
}
```

In `Evaluate` (line 82-85), replace compile+program with the cached program:

```go
out, _, err := rule.program.Eval(activation)
if err != nil {
    return errors.Wrapf(err, "CEL rule %q evaluation error", rule.Name)
}
```
